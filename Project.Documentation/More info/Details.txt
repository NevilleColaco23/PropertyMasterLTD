1.1 -  The queue (e.g. accesslog.queue) appears in the RabbitMQ management UI only after a consumer (like your AccessLogWorker) declares it.
Publishers typically only declare the exchange; queues are created (declared) by consumers when they connect.
If you want the queue to always exist—even before any consumers are running—you can declare it in the publisher code as well, using the same settings, but it’s not required for messages to be routed to an exchange.
